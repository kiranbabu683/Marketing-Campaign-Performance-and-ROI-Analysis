
# Marketing Campaign Performance and ROI Analysis

## Project Overview

This project focuses on analyzing marketing campaign performance and evaluating the effectiveness of different marketing channels using Python.

The analysis explores campaign spending, revenue generation, clicks, Return on Investment (ROI), and monthly performance trends to identify meaningful business insights and support data-driven marketing decisions.

## Business Objectives

- Evaluate the overall performance of marketing campaigns.
- Compare the effectiveness of different marketing channels.
- Analyze the relationship between marketing spend and revenue.
- Calculate and compare campaign-level and channel-level ROI.
- Identify loss-making campaigns.
- Understand monthly ROI trends.
- Generate actionable business insights.

## Dataset Overview

The dataset contains marketing campaign performance information with the following attributes:

| Column | Description |
|---|---|
| Campaign_ID | Unique campaign identifier |
| Date | Campaign date |
| Marketing_channel | Marketing channel used |
| Spend | Amount spent on the campaign |
| Clicks | Number of clicks generated |
| Revenue | Revenue generated |
| ROI % | Recorded return on investment |

**Dataset Dimensions:** 88 rows × 7 columns.

## Tools & Technologies

- Python
- Pandas – Data manipulation and analysis
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical visualization
- Jupyter Notebook – Interactive analysis

## Project Workflow

### 1. Data Loading and Exploration
- Imported the Excel dataset using Pandas.
- Examined dataset dimensions and data types.
- Identified missing values and duplicate campaign IDs.
- Validated date formats.

### 2. Data Cleaning and Preprocessing
- Standardized column names.
- Converted date columns into datetime format.
- Handled missing marketing channel values using an `Unknown` category.
- Checked duplicate campaign identifiers.
- Validated the dataset before analysis.

### 3. ROI Calculation and Validation

Calculated campaign-level ROI using:

ROI (%) = ((Revenue - Spend) / Spend) × 100

- Recalculated ROI using campaign revenue and spending.
- Compared calculated ROI against the supplied ROI values.
- Examined differences to validate data consistency.

### 4. Marketing Channel Performance Analysis

Used GroupBy and aggregation techniques to compare:

- Total number of campaigns.
- Total marketing spend.
- Total revenue generated.
- Total clicks.
- Median and average campaign ROI.
- Pooled ROI by marketing channel.
- Revenue generated per click.

### 5. Correlation Analysis

Examined relationships between:

- Marketing Spend and Revenue.
- Clicks and Revenue.
- Marketing Spend and ROI.

Used correlation coefficients to understand the strength and direction of relationships.

### 6. Loss-Making Campaign Analysis

Identified campaigns with negative ROI to understand potential areas of inefficient marketing expenditure.

### 7. Data Visualization

Developed visualizations to communicate campaign performance:

- Pooled ROI by Marketing Channel – Bar Chart
- Campaign Spend vs Revenue – Scatter Plot
- Monthly Pooled ROI Trends – Line Chart

The analysis is designed to help identify:

- Marketing channels generating higher returns.
- Differences between individual campaign ROI and pooled channel ROI.
